Trabajo Práctico: Introducción a CSS

1. Introducción a CSS

CSS significa Cascading Style Sheets (Hojas de Estilo en Cascada). Es el lenguaje encargado del diseño visual y presentación de documentos estructurados en HTML. Su objetivo principal es separar el contenido de la capa visual, permitiendo definir colores, márgenes, tipografías y diseños adaptables.
